Troubleshooting
===============

No releases are displayed
-------------------------

1. Select **Refresh GitHub Releases** and confirm that the computer can reach GitHub.
2. Check that the release is published and immutable, not a draft.
3. Confirm that the release includes both the manifest and detached signature.
4. Check that the Manager was built with the public key matching the signing key.
5. Confirm that the release has a correctly named installer for the current OS and architecture.

The Manager deliberately omits releases whose signature, manifest, artifact declaration, or platform does not pass validation. A release not appearing does not necessarily mean that no release exists; its assets may be incompatible with the current Manager catalog requirements.

The installer cannot be verified or downloaded
----------------------------------------------

Do not bypass the verification warning by running a downloaded file manually. Check network connectivity and contact the release maintainer if the error persists. The maintainer should verify that the final installer's SHA-256 matches the signed manifest and that the asset size/name are correct. Include the relevant status message and ``weaver-manager.log`` when reporting the issue.

An installation is not listed
-----------------------------

Select **Refresh Installed Versions**. The Manager lists versions containing the expected Weaver CLI executable in its managed program directory or ``/opt/Weaver/<version>/<edition>`` on Linux. On macOS, it checks ``/Applications/Weaver``, ``~/Applications/Weaver``, ``/usr/local``, and ``/usr/local/Weaver``. It does not import installations from arbitrary directories. If a version was removed through the system package manager or another installer, refresh the list.

An action is unavailable
------------------------

Some actions depend on platform or edition. Modify and Uninstall are Windows-only. Open Weaver CLI requires an available terminal: the Manager uses Command Prompt on Windows, Terminal.app on macOS, and a supported terminal emulator on Linux. If it cannot find or open a Linux terminal, install a supported emulator and retry. Hub and GUI are Desktop-only and require their respective components. Hub additionally requires R 4.2 or newer and a discoverable ``Rscript``. Opening R requires R to be installed and discoverable.

An installer fails on Windows
-----------------------------

Wait for the installer process to finish, then review the Manager status and ``msiexec-install.log``. For a Modify operation, inspect ``msiexec-modify.log``. Confirm that the installer supports the system and that you have the permissions it requests before retrying. Do not remove Manager program files while an installer is running.

Need more diagnostic information?
---------------------------------

The Manager log is stored in the Manager data directory under ``logs``. Installer logs are generated by Windows Installer. When contacting a maintainer, include the Manager version, operating system/architecture, Weaver version and edition, exact status/error text, and relevant log files. Avoid sharing sensitive paths or personal data unintentionally.
